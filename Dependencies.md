# Dependencies

This document lists all the known dependencies used in the ODGS-SLAM project, including the licenses of each dependency. Please refer to the respective licenses for more details on the usage and distribution of each dependency.

## MonoGS

Since ODGS-SLAM builds on MonoGS (commit 6c9254c) as its base, it inherits all its dependencies and licenses. Please follow the license of MonoGS for any usage of ODGS-SLAM.

License URL: <https://github.com/muskie82/MonoGS/blob/main/LICENSE.md>
